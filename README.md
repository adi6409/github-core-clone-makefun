A single-process Node.js 22 forge implementing a tested subset of Git smart HTTP, REST, GraphQL, and MCP interfaces for the make.fun GitHub-compatible forge challenge. This is a partial implementation; see the official check and remaining-check list before relying on supported behavior.

## Run

Requires Node.js 22.18.0 or compatible Node 22. Start from the repository root:

```sh
node --experimental-strip-types main.ts
```

The entry point uses Node's standard library and requires no package installation.
